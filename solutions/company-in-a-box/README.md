# Services Company in a Box

Les Modules de base sont [Veille](modules/veille/module.yaml),
[Contenu](modules/contenu/module.yaml) et
[Accompagnement](modules/accompagnement/module.yaml), version 0.2.4.
Le composeur [template/compose.py](template/compose.py) les copie dans les trois
Agents préinitialisés du projet consommateur, en preview par défaut.

La [mémoire autonome](../company-memory/README.md), son
[intégration](memory-integration/README.md), la
[routine quotidienne](daily-routine/README.md), les
[dossiers et Direction](common-dossier/README.md),
[l’administration](enterprise-admin/README.md) et le
[Marketing de lancement](marketing-launch/README.md) sont composables selon
les besoins de l’entreprise.

Voir [installation](../../docs/INSTALLATION.md),
[droits](../../docs/SECURITY.md) et [tests](../../docs/TESTING.md).
Les données, comptes et droits sont ceux de l’instance destinataire, jamais
ceux d’une entreprise source. Le mode initial est manuel, sans effet externe.
